# MetaSafe UI Icon Map

All icons are 24x24 outline SVGs using `stroke="currentColor"` so they can inherit theme colors, including the MetaSafe blue-to-emerald brand treatment from CSS.

| Icon file | Replaces emoji | Recommended use |
| --- | --- | --- |
| `shield-check.svg` | 🛡️ / ✅ | Cleaned, safe, protected status; final success summary. |
| `lock.svg` | 🔒 | Privacy, encryption, local-only/offline assurance. |
| `file-image.svg` | 🖼️ / 📄 | Image file type rows and upload result badges. |
| `file-doc.svg` | 📄 | Generic document file type rows. |
| `file-pdf.svg` | 📄 | PDF file type rows and PDF metadata cleaning labels. |
| `file-audio.svg` | 🎵 / 📄 | Audio file type rows. |
| `file-video.svg` | 🎬 / 📄 | Video file type rows. |
| `file-email.svg` | ✉️ / 📧 | Email message file type rows or email metadata section. |
| `trash.svg` | 🗑️ | Remove file, clear item, delete output actions. |
| `folder.svg` | 📁 | Select folder, choose files, browse local files. |
| `drag-drop.svg` | 📄 / ⬇️ | Drag-and-drop file area; offline file import without cloud implication. |
| `settings-gear.svg` | ⚙️ | Settings, preferences, processing options. |
| `link-broken.svg` | 🔗 | URL cleaner, link tracking removal, broken/cleaned link state. |
| `map-pin.svg` | 📍 | GPS/location metadata warning and location removal. |
| `sun-moon.svg` | ☀️ / 🌙 | Theme toggle button. |
| `qr-code.svg` | 📱 / QR | Certificate QR code and verification sharing. |
| `warning-triangle.svg` | ⚠️ | Risk warning, metadata found, caution states. |
| `check-circle.svg` | ✅ | Verification passed, completed action, success toast. |
| `x-circle.svg` | ❌ | Error, failed verification, unsupported file state. |
| `redact-box.svg` | █ / 🧹 | Redaction feature; hide sensitive text/regions in a document or image. |
| `panic-button.svg` | 🧹 / 🗑️ / ⚡ | Panic delete or emergency quick-clean action. |
| `correlation-link.svg` | 🔗 / 📍 | Bulk correlation risk feature; connected metadata points and relationship analysis. |
